    20→## KONTRAK API (src/app/api/...)
    21→
    22→Semua route mengembalikan `{ ok: true, data: ... }` atau `{ ok: false, error: string }`.
    23→
    24→1. **GET /api/stats** → data:
    25→   ```ts
    26→   {
    27→     totals: { certificateHolders: number, institutions: number, experts: number, programs: number, verificationsToday: number, applicationsThisMonth: number },
    28→     programDistribution: { code: string, holders: number }[], // dari Program.holderCount
    29→     tierDistribution: { tier: string, count: number }[],      // SILVER/GOLD/PLATINUM dari Institution
    30→     recentActivity: { certNumber: string, result: string, at: string }[], // 8 terbaru dari VerifyLog desc
    31→     topProvinces: { province: string, count: number }[]       // 6 teratas dari Institution
    32→   }
    33→   ```
    34→
    35→2. **GET /api/programs** → `data: Program[]` (semua field model Program; `requirements` & `benefits` & `accreditation` berupa string JSON — parse di client).
    36→
    37→3. **POST /api/verify** body `{ certNumber: string }` → cari Institution by certNumber (case-insensitive, trim):
    38→   - ditemukan → `{ ok: true, data: { valid: true, institution: Institution, program: { code, name } | null } }` + simpan VerifyLog VALID.
    39→   - tidak → `{ ok: true, data: { valid: false } }` + simpan VerifyLog INVALID.
    40→   - body kosong → `{ ok: false, error: "..." }` HTTP 400.
    41→
    42→4. **GET /api/directory?q=&type=&tier=&city=** → `data: Institution[]` (filter opsional; q = nama ATAU certNumber contains; sorted tier PLATINUM>GOLD>SILVER lalu score desc; max 50).
    43→
    44→5. **GET /api/experts** → `data: Expert[]` (46 pakar, sorted featured desc, name asc).
    45→
    46→6. **GET /api/news** → `data: NewsArticle[]` desc by publishedAt.
    47→
    48→7. **POST /api/applications** body `{ applicantType, programCode, fullName, email, phone, institution?, city, message? }`:
    49→   - Validasi zod: fullName>=3, email valid, phone>=9 digit, programCode harus ada di tabel Program.
    50→   - Generate trackingCode `PSK-2025-{5 digit acak}` (unique check loop).
    51→   - Simpan status default SUBMITTED → `{ ok: true, data: { trackingCode, status } }`.
    52→
    53→8. **GET /api/applications?code=PSK-2025-XXXXX** → cari by trackingCode (case-insensitive):
    54→   - ditemukan → `{ ok: true, data: { trackingCode, programCode, status, fullName, createdAt, statusHistory: [{ label, at, done: boolean }] } }` — statusHistory di-generate berdasarkan tahap SUBMITTED→REVIEW→VERIFIKASI→ASSESSMENT→APPROVED.
    55→   - tidak → `{ ok: false, error: "..." }` HTTP 404.
    56→
    57→9. **POST /api/contact** body `{ name, email, subject, message }` → simpan ContactMessage → `{ ok: true, data: { received: true } }`.
